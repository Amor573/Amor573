## 🧭 How I approach engineering

1. **Design for repeatability:** use version-controlled configuration and infrastructure code.
2. **Secure by default:** least privilege, careful secret handling and reviewable changes.
3. **Make systems observable:** meaningful metrics, logs and clear troubleshooting paths.
4. **Validate claims:** distinguish working deployments from untested examples and design exercises.
5. **Document the operations path:** setup, verification, failure modes and rollback/recovery.
